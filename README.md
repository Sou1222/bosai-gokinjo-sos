# 防災ご近所SOS

災害発生直後、行政の支援(公助)が届くまでの「空白の72時間」を、
ご近所同士の助け合い(共助)でつなぐマッチングアプリのプロトタイプ。

---

## 1. 企画書（コンテスト提出用サマリー）

### 課題設定
大地震などの直後は、行政・消防・自治体の支援が現場に届くまで
数時間〜数日のタイムラグが生じる。この間、水・食料の不足、
高齢者や要介護者の安否確認、瓦礫の下敷きなど、
「今すぐ隣の人の手を借りれば解決すること」が数多く発生するが、
それを繋ぐ仕組みが存在しない（SNSは情報が流れて消え、正確な位置情報もない）。

### ターゲットユーザー
- 平常時: 自治体の防災訓練・自主防災組織・マンション管理組合
- 有事: 被災地域の住民（要支援者・支援可能者の双方）

### ソリューション
1. 困っている人が「カテゴリ・緊急度・詳細」付きでSOSを投稿
2. 事前 or 発災直後に登録された「協力できること」を持つ近隣住民から、
   **距離・スキル一致・緊急度** の3軸でスコアリングした候補を自動表示
3. 依頼者が対応してほしい人に直接連絡し、解決したらステータスを更新

### 差別化ポイント
- 既存の防災SNS/掲示板は「投稿するだけ」で終わるが、本アプリは
  **誰に頼めばいいかまでレコメンドする**（マッチングアルゴリズムが核）
- 平常時から自主防災組織の名簿として「協力スキル」を登録しておくことで、
  発災直後も土地勘のある人がすぐ動ける
- オフライン耐性を見据え、将来的にはBluetooth/メッシュネットワーク対応や
  PWA化によるオフラインキャッシュも拡張可能（ロードマップに記載）

### マッチングロジック（本プロトタイプの実装）
候補協力者のスコアは以下の加重和で算出（`app.py` の `score_match`）:

```
score = 0.5 × 距離スコア + 0.3 × スキル一致スコア + 0.2 × 緊急度スコア
```

- 距離スコア: 半径2km以内を対象に、近いほど1.0に近づく線形スコア
- スキル一致スコア: 依頼カテゴリと協力者の登録スキルが一致すれば1.0、しなければ0.2
- 緊急度スコア: 依頼の緊急度(緊急=3/高=2/中=1)を3で正規化

半径2km・重み付けは自治体規模や地形に応じてパラメータ調整可能。

### ビジネスモデル / 継続性（例）
- 自治体・マンション管理組合向けの防災訓練SaaSとして平時から名簿整備し、
  年間ライセンス料で提供
- 将来的には社会福祉協議会・自主防災組織との連携で「共助の見える化」データを提供

### デモシナリオ（審査員向け）
1. 地図をクリックして「② 協力者登録」に座標を入力し、近隣住民を2〜3人登録
2. 地図クリック先を「① SOS投稿」に切り替え、地図上の別地点をクリックしてSOSを投稿
3. 実際のOpenStreetMap上に赤(SOS)と青(協力者)がプロットされ、破線でマッチ候補が結ばれる様子・一覧にスコア順の候補が表示される様子を見せる
4. 「解決済みにする」を押して運用フローが一巡することを見せる

### 今後の展望（ロードマップ）
- PWA化してオフラインでも投稿をキューイングし、電波復旧時に自動送信
- 自治体のハザードマップ・避難所情報との連携
- 認証・なりすまし対策（自治会の名簿とのID連携）
- 音声入力対応（高齢者向けのUXバリアフリー化）

## 2. セットアップ方法

```bash
cd bosai-gokinjo-sos
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python app.py
```

起動後、ブラウザで `http://127.0.0.1:5001` にアクセス。

初回起動時に `sos.db`（SQLite）が自動作成されます。
データをリセットしたい場合は `sos.db` を削除して再起動してください。

## 3. 使い方

1. 地図上部のラジオボタンで「① SOS投稿フォームへ」「② 協力者登録フォームへ」を切り替え、
   実際の地図（OpenStreetMap）をクリックすると緯度経度が自動入力される
2. 「② 協力できることを登録する」で、近隣の協力者を登録（対応可能スキルを選択）
3. 「① 助けてほしいことを投稿する」で、SOSを投稿（カテゴリ・緊急度・詳細）
4. 地図上に赤(SOS)・青(協力者)のマーカーが表示され、マッチ候補は破線で結ばれる
5. 「④ SOS一覧とマッチング結果」にスコアの高い順で協力候補が自動表示される
6. 対応が終わったら「解決済みにする」をクリック

地図タイルは OpenStreetMap を利用しているため、動作にはインターネット接続が必要です。
初期表示は東京駅(35.681, 139.767)周辺です。
